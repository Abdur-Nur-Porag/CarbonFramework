# Drawer Documention

```html

    <button class="btn-trigger" onclick="openDrawer('NavDrawer')">Open Left Drawer</button>
    <button class="btn-trigger" onclick="openDrawer('SettingsDrawer')">Open Right Drawer</button>

    <Drawer Name="NavDrawer" Position="Left" Elevation="5">
      
    </Drawer>

    <Drawer Name="SettingsDrawer" Position="Right" Elevation="10">
      
    </Drawer>

```
## trigger
- openDrawer(name)
## Position
- left
- right
## Elevation
- 0(min) to 10(max)
