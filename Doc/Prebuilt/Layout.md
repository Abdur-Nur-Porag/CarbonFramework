# Layout Documention
There is no extra Prebuilt for layout.
Layout automatic handel by `pageview`
```html
<PageView Name="">
  <App>
    <AppBar></AppBar>
    <AppBody></AppBody>
    <BottomBar></BottomBar>
  </App>
</PageView>
```
For extra to scroll use.
```html
  ScrollBar=true/false
  Type=VScroll/HScroll
```
