# Introduction
This is first basic example for beginner.
## Initial Setup
1. Open `Terminal`
2. Then run command `cd your-project-folder`
3. Then run command `node CarbonCli.js --sync`
4. Then run command `node LiveServer.js`
Then you will see in terminal `
===============================
🚀 CARBON LIVE SERVER RUNNING
🔗 Open in browser:http://localhost:3000
 📂 Watching file system for changes...
===============================
`

This means server run successfully.

😎😎Your Initial Setup Complete.

## Writing Hello,World
😁Ready for `first` writing your own app.
1. Open `Main/Views/HomeView.jsx`
Write This inside `<PageView>` tag:
```jsx
<App>
	<AppBody>
		<H6>Hello,World</H6>
	</AppBody>
</App>
```
Ok save it.
2. Then open browser [http://localhost:3000](http://localhost:3000)
🌟🌟🌟🌟Your Complete Your Basic Lesson🌟🌟🌟🌟
